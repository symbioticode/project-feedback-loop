# Architecture

The system separates authority, knowledge, observation, projection, context,
and scheduling:

```text
sources → declarations and observations → normalized registry
        → human and machine projections → shared AI context
```

MyCollabIA owns explicit lifecycle decisions. MyKnowledgeBase preserves meaning
and provenance. Observers produce signals, not truth. Dashboards and context
files are derived views. A scheduler only starts the refresh command.
